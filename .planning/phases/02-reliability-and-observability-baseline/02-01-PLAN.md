<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| startup runtime -> telemetry provider | Untrusted exception payloads cross process boundary |
| plugin/service failures -> user messaging | Internal errors converted into user-visible state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | I | telemetry payload | mitigate | scrub sensitive context in telemetry adapter and send only domain/code tags + safe message |
| T-02-02 | D | startup sequence | mitigate | explicit criticality map with fail-fast for critical steps and degraded mode for non-critical steps |
| T-02-03 | R | startup failure events | mitigate | route all startup/service errors through unified DomainError + telemetry capture for auditability |
</threat_model>
